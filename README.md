# نغمة – تطبيق التعرّف على الأغاني (Android)

1. افتح المجلد في Android Studio (Koala أو أحدث).
2. سجّل في https://dashboard.audd.io وانسخ مفتاح API.
3. ضعه في ملف local.properties:  AUDD_TOKEN=مفتاحك
4. وصّل هاتفك (تصحيح USB) واضغط Run ▶.
5. للحصول على APK: Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s).
